# syrup-desk

Twisted Syrup, a half-time production desk. 60-68 bpm, minor keys, six buses.

It is not a DAW and not a BandLab clone: one sound, one workflow.

- 808 sub with a 96 ms legato glide, soft-clip harmonics, 120 Hz ceiling
- kick sidechain ducking the sub
- triplet hats, DJ Screw tape stop and stutter
- cavernous wash: 60 ms pre-delay, 6.5 s decay, dark stereo tape delay
- four blueprints, offline bounce to WAV, upload and mic through the same chain
